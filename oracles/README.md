# TrionChain Oracles (Active)

This directory contains **active oracle interfaces** compatible with the current TrionChain runtime and mesh-based validation model.

These oracles:
- Resolve physical data off-chain
- Submit state updates to the TrionChain Layer-1
- Are designed to work with the current runtime pallets and mesh logic

> Legacy and research oracle implementations have been moved to `research/legacy/oracles` for historical reference.
